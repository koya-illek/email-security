What this tool measures

DNS

DNS observation

SPF, DKIM, DMARC, MX, and CAA records resolved via DNS-over-HTTPS. Transport security checks MTA-STS and TLS-RPT policies. Batch checks compare up to 3 domains.

HDR

Header evidence

Header analysis parses Authentication-Results claims, Received-SPF results, DKIM-Signature field shape, message addresses, and Received hops. It does not independently verify a DKIM signature or re-run authentication.

ƒ(x)

Derived finding

Interpretation of DNS records and header evidence, with recommendations grounded in published RFCs and current best practice. Reports can be read for up to 14 days; expired rows are removed by an hourly cleanup, and expired links stop working immediately.

This tool does not test deliverability, send email, or probe private infrastructure. DKIM selector discovery is best-effort and may not find all active selectors.
