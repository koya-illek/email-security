# Contributing

Bug reports and focused pull requests are welcome.

## Report a bug

Search existing issues first, then use the bug-report template. Include steps
that reproduce the problem, your browser or runtime, and what you expected.
Remove credentials, personal data and private report links from any evidence.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md).

## Propose a change

Open an issue before starting a substantial feature so its scope can be discussed.
For a small fix, open a pull request that explains the problem, the change and
how you checked it.

Follow the setup instructions in [README.md](README.md). Run the checks relevant
to your change and report their results in the pull request. For interface changes,
include a screenshot and check the affected workflow in a browser.
